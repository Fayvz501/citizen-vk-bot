# citizen-vk-bot

VK-бот для интеграции с системой **Citizen Monitor**.

Проект принимает сообщения от пользователей во ВКонтакте, показывает список происшествий, статистику и лидерборд, а также умеет отправлять уведомления о новых событиях из основного приложения Citizen.

## Возможности

- просмотр активных происшествий за последние 24 часа;
- получение подробной информации по событию;
- статистика за 7 дней;
- лидерборд пользователей;
- оценка безопасности района;
- подписка и отписка от уведомлений;
- авторассылка новых происшествий;
- webhook-сервер для мгновенных уведомлений из основного приложения.

## Структура проекта

- `vk_bot.py` — основной файл бота;
- `.env.example` — пример переменных окружения;
- `requirements.txt` — зависимости Python;
- `render.yaml` — конфигурация для деплоя на Render.

## Требования

- Python 3.10+;
- сообщество VK с включёнными сообщениями;
- ключ доступа сообщества VK;
- основной backend Citizen с доступным API.

## Переменные окружения

Пример указан в файле `.env.example`:

```env
VK_GROUP_TOKEN=vk1.a.xxxxxxxx
VK_GROUP_ID=123456789
VK_NOTIFY_PEER_ID=
VK_ADMIN_IDS=
CITIZEN_API_URL=https://your-citizen-app.onrender.com/api
WEBHOOK_PORT=5050
```

### Описание переменных

- `VK_GROUP_TOKEN` — токен сообщества VK;
- `VK_GROUP_ID` — ID сообщества;
- `VK_NOTIFY_PEER_ID` — ID беседы или диалога для служебных уведомлений;
- `VK_ADMIN_IDS` — список ID администраторов через запятую;
- `CITIZEN_API_URL` — адрес API основного приложения Citizen;
- `WEBHOOK_PORT` — порт встроенного webhook-сервера;
- `POLL_INTERVAL` — интервал опроса API в секундах, по умолчанию `10`.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/Fayvz501/citizen-vk-bot.git
cd citizen-vk-bot
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка окружения

Создайте `.env` на основе `.env.example` и заполните своими значениями.

### 4. Запуск

```bash
python vk_bot.py
```

## Команды бота

- `/start` или `/help` — помощь;
- `/live` — активные происшествия;
- `/stats` — статистика;
- `/top` — лидерборд;
- `/map` — ссылка на карту;
- `/subscribe` — подписка на уведомления;
- `/unsubscribe` — отписка;
- `/safety` — безопасность района;
- число (`1`, `2`, `3` ...) — подробности о выбранном происшествии.

## Webhook-уведомления

Бот поднимает встроенный HTTP-сервер и принимает POST-запросы по следующим маршрутам:

- `/notify/incident`
- `/notify/sos`
- `/notify/emergency`
- `/notify/status`
- `/notify/comment`
- `/notify/streamer`

Эти маршруты можно использовать из основного приложения Citizen для мгновенной отправки уведомлений в VK.

## Деплой на Render

В проекте уже есть `render.yaml`.

Основные шаги:

1. создать новый сервис на Render;
2. подключить репозиторий;
3. указать переменные окружения;
4. запустить деплой.

По умолчанию используется:

- build command: `pip install -r requirements.txt`
- start command: `python vk_bot.py`

## Зависимости

Список зависимостей указан в `requirements.txt`:

- `vk-api==11.9.9`
- `requests==2.31.0`
- `python-dotenv==1.0.0`

## Примечание

Этот репозиторий содержит только VK-бота. Основное веб-приложение Citizen и его backend/API должны быть развернуты отдельно.
